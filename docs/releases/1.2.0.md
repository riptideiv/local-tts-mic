## Installation

Download **local-tts-mic-1.2.0-arm64-unsigned.pkg** below. Requires **Apple Silicon and macOS 15 or newer**.

**This is an unsigned, unnotarized preview.** The app has an ad-hoc code seal; neither the app nor installer has a Developer ID distribution signature or Apple notarization. macOS may block it. Review [installation and Gatekeeper guidance](https://github.com/riptideiv/local-tts-mic/blob/v1.2.0/docs/INSTALL.md) before deciding to allow it.

1. Finish calls and quit Local TTS Mic. Open the `.pkg` and follow Installer. It asks for administrator authentication and **briefly restarts all Mac audio** to install the virtual microphone.
2. Open Local TTS Mic from Applications and complete **Install / repair**. First launch downloads several GB of models and examples; allow at least **10 GB free**. No Terminal, Git, Homebrew, or developer tools are needed.
3. Try Preview, then select Local TTS Mic as the microphone in your call/game app.

## Changes

- App-and-driver installer with bundled Python/dependencies and per-user model storage.
- Hugging Face URL and downloaded-folder voice import, with pinned downloads, checksum verification, and metadata review.
- Small community catalogue with source and usage terms shown before download.
- GPT-SoVITS **v1, v2, v2Pro, and v2ProPlus** checkpoint import. v1 requires a matching pair; see the [Nene example](https://github.com/riptideiv/local-tts-mic/blob/v1.2.0/docs/VOICES.md#v1-checkpoints).
- Model switching clears cached reference features; private voice previews retain your broadcast selection.

## Validation and limitations

24 Swift tests and 35 Python tests pass, alongside native build, driver harness/sanitizers, and code-seal checks. Real v1 Japanese synthesis, native private preview, and switching v1 → v2ProPlus → v1 passed. The preceding installer was installed/tested successfully by the owner.

Fresh setup on additional Macs, minimum RAM, broader call-app compatibility, and signed/notarized distribution remain unverified. CPU is the default; MPS is experimental. Models/reference voices have separate terms from the MIT app; no community weights or recordings are bundled.

`SHA256SUMS` covers the installer and committed-source archive. The source archive is for contributors; ordinary Mac users should choose the `.pkg`.
