# Third-party components and reference recordings

- **GPT-SoVITS** — RVC-Boss and contributors, MIT. Source: https://github.com/RVC-Boss/GPT-SoVITS. Pinned commit: `b4570b876f5c086819ba84e3215472733c6a7b70`. Original source and license are retained in `runtime/GPT-SoVITS/` after setup.
- **Pretrained speech models** — https://huggingface.co/lj1995/GPT-SoVITS, revision `8f8857563c040d542de108a2c18b0425abd6c9c5`. Additional BERT vocabulary: https://huggingface.co/hfl/chinese-roberta-wwm-ext-large. Chinese pronunciation model: https://huggingface.co/XXXXRT/GPT-SoVITS-Pretrained. Model metadata is retained in `runtime/model-manifest.json`.
- **LJ Speech** — Keith Ito and Linda Johnson; reference LJ001-0001, via the `klein-ml/LJSpeech-1.1-24KHz` mirror. Public domain audio and text. Source and description: https://keithito.com/LJ-Speech-Dataset/.
- **AISHELL-3** — Beijing Shell Shell Technology Co., Ltd.; reference SSB00050353, speaker SSB0005. Apache License 2.0. Source: https://www.openslr.org/93/; direct mirror: https://huggingface.co/datasets/AISHELL/AISHELL-3.
- **JSUT** — Ryosuke Sonobe, Shinnosuke Takamichi, and Hiroshi Saruwatari, University of Tokyo; reference BASIC5000_0001, via `japanese-asr/ja_asr.jsut_basic5000`. The audio permits personal use and non-commercial research; commercial use requires permission. Corpus redistribution is restricted. Text licensing includes CC BY-SA 4.0; consult the corpus LICENSE. This repository stores source metadata and downloads one recording locally; it does not contain the corpus recording. Source/terms: https://sites.google.com/site/shinnosuketakamichi/publication/jsut. Citation: Sonobe, Takamichi, Saruwatari, “JSUT corpus: free large-scale Japanese speech corpus for end-to-end speech synthesis,” arXiv:1711.00354, 2017.
- **Local TTS Mic driver scaffolding** — derived from Apple’s MIT-licensed Audio Server Driver Plug-in sample. The original source and license are in `driver/vendor/`; archive and source hashes are pinned in `driver/upstream.json`. Local loopback and PCM transport additions are in `driver/Loopback.h` and `Sources/CMicTransport/`. https://developer.apple.com/documentation/coreaudio/creating-an-audio-server-driver-plug-in.
- **FastText language model** — Meta/Facebook fastText language identification model, lid.176.bin. https://fasttext.cc/docs/en/language-identification.html (model: CC BY-SA 3.0).
- Python runtime dependencies and exact versions are listed in `requirements.lock`; each installed package retains its own license metadata. An optional local Whisper model used for validation is stored only under `runtime/asr/`.

The project MIT license applies to original app/driver code, not to downloaded weights, dependency packages, or corpus recordings. Review the linked model cards and original terms for your intended use; this notice is not a blanket commercial license for generated voices. Setup does not redistribute model files with source packages. The Japanese JSUT reference is opt-in via `--include-jsut`; normal setup installs only English and Mandarin references.

Supplemental resource and reference SHA-256 pins are in `resources/asset-checksums.json` and `resources/starter-sources.json`. These record inspected local bytes; mutable upstream mirrors must continue matching those pins or setup fails for review. Main speech weights use LFS hashes from the pinned model revision. Python package versions are pinned in requirements.lock without package artifact hashes.

## Packaged runtime

The macOS package builder includes a standalone CPython distribution provided by Astral's [python-build-standalone](https://github.com/astral-sh/python-build-standalone), the packages pinned in `requirements.lock`, and the [Open JTalk dictionary](https://github.com/r9y9/open_jtalk/releases/tag/v1.11.1) used by pyopenjtalk. Their license and package metadata files remain inside the embedded Python distribution; the dictionary contains its original notices. Dependency licenses are separate from the app's MIT license. Review them before distributing a binary package.

Packaged first-run setup downloads the official [imageio-ffmpeg 0.6.0 Apple Silicon wheel](https://pypi.org/project/imageio-ffmpeg/0.6.0/) directly from PyPI, checks its pinned SHA-256, and extracts its FFmpeg executable into the user's managed runtime. The wheel and its notices are retained there. FFmpeg is not redistributed inside the app or installer; see the [imageio-ffmpeg project](https://github.com/imageio/imageio-ffmpeg) and [FFmpeg licensing](https://ffmpeg.org/legal.html) for its separate terms and source information.
