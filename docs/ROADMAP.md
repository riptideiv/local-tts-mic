# Roadmap

The first release is deliberately a source preview for Apple Silicon users comfortable with a terminal. Feedback should decide what comes next.

| Priority | Outcome | Definition of done |
| --- | --- | --- |
| Next | Setup works on a second Mac | Fresh setup/preview evidence with chip, memory, OS, and timing; fix any blockers found |
| Next | Call-app compatibility reports | Document receiving-app version/settings and received audio, not just app queue completion |
| Next | Easier downloads | Move runtime from the build path into managed app support, review redistribution terms, sign + notarize app/installer, clean-machine install/remove test |
| Next | Long-session confidence | Soak with idle intervals, cancellation, sleep/wake, device changes, and bounded disk/log retention |
| Later | Faster first audio | Compare engines on the same texts/references/hardware with latency and quality evidence |
| Later | More accessible setup | VoiceOver pass, keyboard-only onboarding, clearer progress and storage controls |
| Later | Engine options | Add an adapter only after a concrete use case, license check, and comparable validation |

There are no promised dates. Windows/Linux UI, microphone mixing, or bundled celebrity/character voices are not supported in this preview.
